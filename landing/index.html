界面示意 · 失效文件标灰保留，⌘Z 找回

菜单栏，是 macOS 上离你手最近的一块地。

可它现在只摆着一个时钟。要点穿的目录层级、要解锁的验证码 App、散在五个窗口里的 Agent 用量——它们都在等你回头。Pinner 把这块地变成钉板。

  • 01同一个文件夹，每天在 Finder 里点穿四层。
  • 02解锁、找 App、等刷新——验证码只剩五秒。
  • 03五个 Agent 各烧各的，月底对不上账。

这些活，一枚图钉就够了。

01 · 收藏夹 ⌘⇧P

文件去哪了，
不用再想。

从 Finder 拖进来，就钉住了。三层目录之外的日常文件，从此都在菜单栏一跳以内。

  • 01拖拽收藏，路径去重；多选批量移动、⇧ 范围选择，Delete 直接删，⌘Z 找回。
  • 02输入即搜，拼音首字母也能命中——zb 匹配「项目周报」，跨所有收藏夹分组。
  • 03空格 Quick Look 预览，方向键切换、预览实时跟随；列表 / 宫格两种视图随意换。
  • 04失效文件标灰保留，绝不静默删除——文件找回，标记自动解除。

验证码亮起的第三秒，
已经在剪贴板里。

全局快捷键弹出面板的瞬间，当前验证码已自动复制。倒计时走完自动换码，永远是新的。

  • 01RFC 6238 标准 TOTP，本地生成，绝不上传。
  • 02粘贴 otpauth:// 链接，或从本地图片识别二维码，即可添加账户。
  • 03独立浮动窗，≤10 秒变红提醒，周期走完自动翻新。

# Mac 端贴边收藏箱 App 设计

## 目标
做一个 macOS 菜单栏常驻工具，允许用户把文件/文件夹拖入分类 tab 中收藏，并通过贴边悬浮面板快速打开。

## 用户场景
- 我正在处理一组常用文件，希望把它们按主题收纳起来。
- 我不想改变原文件位置，只想建立入口，随时快速打开。
- 我希望这个工具平时不打扰我，但需要时能从屏幕右侧快速展开。

## 交互设计
- 应用常驻菜单栏，不占 Dock。
- 默认显示为屏幕右侧贴边的小半透明面板，鼠标移入后向屏幕内展开。
- 提供全局快捷键作为备用唤出方式。
- 展开后显示 tab 栏和当前 tab 的入口列表；同时可见约 10 个入口，超出部分滚动查看。

## 功能设计
- Tab 是用户自定义分类，支持新增、重命名、删除、拖拽排序。
- 支持从 Finder 拖拽文件或文件夹进入指定 tab。
- 入口以 bookmark 形式保存，源文件不移动。
- 点击文件使用系统默认应用打开。
- 点击文件夹直接在 Finder 中打开。
- 删除入口只移除收藏，不删除源文件。

## 数据与持久化
- 本地持久化所有 tab、入口、排序、窗口位置和上次展开状态。
- 启动后恢复上次状态，避免用户重复整理。
- v1 不做 iCloud 同步，优先保证单机体验稳定。

## 技术方案
- 采用 SwiftUI + AppKit 混合架构。
- SwiftUI 负责主体界面、列表、tab 与状态展示。
- AppKit 负责菜单栏、悬浮窗、边缘触发、窗口层级和全局热键。

## 范围边界
- v1 只做拖拽导入，不做 Finder 右键“加入收藏箱”。
- v1 不做内嵌预览，只做快速打开。
- v1 不做多设备同步。

## 错误处理
- bookmark 失效时，入口标记为不可用，并提供重新定位或移除。
- 打开失败时保留入口，不静默删除数据。
- 拖拽非法类型时给出明确反馈。

## 验证重点
- 贴边收起与展开是否稳定。
- 拖拽导入、点击打开、移除入口是否符合预期。
- 重启后是否恢复 tab、入口和窗口状态。
- 全局快捷键与菜单栏常驻是否可用。

## Assumptions
- 默认只面向单机使用。
- 默认右侧边缘触发展开。
- 默认使用 SwiftUI + AppKit 混合实现。
